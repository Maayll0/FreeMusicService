# Проверка бэкенда

На чистой базе PostgreSQL 17 миграция Alembic `2bb3ee6e16c8` создаёт таблицы и представление `listener_music_catalog`. Запрос каталога на пустой базе возвращает пустой список.

В Docker прошли 17 тестов pytest. Проверены регистрация, вход, выход, поиск, получение файла, ответы 401 и 403, отсутствие файла и ограничение пути к аудио.

Для повторения на отдельной тестовой базе:

```sh
docker compose -p freemusic-tests run --rm backend sh -c "alembic upgrade head && pytest -q"
```

Порт базы 5433 на компьютере должен быть свободен. Тесты создают собственные записи и временные аудиофайлы.
