# Демонстрация FreeMusicService

1. Запустите проект по основному README и откройте `/docs`. Выполните `GET /api/tracks`. Каталог доступен до входа и читает данные из представления `listener_music_catalog`.
2. Запросите `GET /api/tracks/1/stream` до входа. Сервер вернёт 401.
3. Зарегистрируйте тестового пользователя с уникальными логином и email, затем выполните вход. Проверьте профиль через `GET /api/me`. При показе параметров cookie скройте значение JWT.
4. На отдельной тестовой базе запустите проверки по инструкции в verification.md. В тестах поток с допуском 1 возвращает разрешённый файл, запрос песни уровня 2 от того же слушателя получает 403. Для проверки пути тест создаёт настоящий файл за пределами каталога аудио и ожидает 404.
