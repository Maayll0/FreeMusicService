# FreeMusicService

Учебный API музыкального каталога по ПАСЗИ. Посетители могут искать песни по названию и исполнителю. Для получения аудиофайла нужны вход в аккаунт и достаточный допуск.

## Запуск

Скопируйте `.env.example` в `.env`, задайте свои значения `POSTGRES_PASSWORD` и `JWT_SECRET`, оставьте `PORT=8000`. Из корня проекта выполните:

```sh
docker compose up -d --wait db
docker compose run --rm -p 127.0.0.1:8000:8000 backend
```

Откройте http://localhost:8000/docs. При запуске бэкенда Alembic создаёт таблицы и представление каталога. В новой базе песен пока нет.

## Мандатный доступ

Сервер выдаёт файл, если допуск пользователя не ниже уровня песни. Новый пользователь получает уровень 0. Пример для трёх числовых уровней:

| Допуск пользователя | Песня 0 | Песня 1 | Песня 2 |
|---|---|---|---|
| 0 | Доступно | 403 | 403 |
| 1 | Доступно | Доступно | 403 |
| 2 | Доступно | Доступно | Доступно |

## Безопасность

- SQLAlchemy передаёт значения отдельно от SQL. Длина поисковых полей ограничена, а символы `%` и `_` в поиске обрабатываются буквально.
- Браузер получает JWT в cookie с `HttpOnly` и `SameSite=Lax`. На защищённых маршрутах сервер проверяет подпись HS256, срок токена и наличие пользователя в БД. При запуске процесса с `APP_ENV=production` cookie получает атрибут `Secure` для HTTPS.
- Перед чтением файла сервер проверяет допуск и полный путь. Разрешено читать файлы только из каталога аудио. Без входа сервер возвращает 401.
- Пароли хранятся в виде хешей Argon2id с индивидуальной случайной солью.
- Pydantic проверяет логин, пароль и формат переданного email. При регистрации, входе и удалении аккаунта дополнительные поля отклоняются.
